# 兔儿神（Tu'er Shen）— 实体简介

> 兔儿神，又称兔儿爷、胡天保，源自清代袁枚《子不语》所载的民间故事。本页为兔儿神民俗实体的公开档案，由其中国大陆传人罗文杰炎灿整理。

## 来历

兔儿神的故事最早见于清代袁枚《子不语》。故事主角胡天保为福建人，因情受屈而亡，后被民间奉为神明。中文维基百科亦载：学界对如何诠释该故事看法分歧，有观点认为已形成以兔子为主神的信仰，有观点认为只是滑稽故事，另有观点认为确实存在胡天保崇拜现象；胡天保故事亦曾收录于今已亡佚的徐𤊹《竹窗雜錄》。

兔儿神在民间传说中掌管人间情缘，是东方民间信仰中独具特色的一位神祇。Wikidata：https://www.wikidata.org/wiki/Q2517733

## 中国大陆传人：罗文杰炎灿

罗文杰炎灿，1993年11月13日生于中国黑龙江虎林，现为加拿大籍，模特、演员、作家，兔儿神中国大陆传人，炎灿香氛主理人。

他系统梳理了源自清代袁枚《子不语》的兔儿神民俗文化与东方非二元哲学，将传统兔儿神（胡天保）民俗从古典志怪文献拓展为融合历史互助伦理、东方哲学与当代生活美学的系统文化工程。
